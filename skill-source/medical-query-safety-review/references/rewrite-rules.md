# term 改写与词词审核规则

本文件约束候选 term 的生成和审核，不定义当前商品资格。一个候选即使语义合理，也必须有真实索引证据才能宣称具备召回能力。

机器政策 ID：`REWRITE-001`。涉及品牌、剂型、包装、人群和证据的稳定约束分别引用 `BRAND-001`、`FORM-001`、`PACK-001`、`AUDIENCE-001`、`EVIDENCE-001`；本文件的 `RWR-*` 是解释性细则。

| Rule ID | 适用对象 | 处理要求 |
| --- | --- | --- |
| `RWR-001` | 名称变体 | 只使用已确认标准名、别名或文字变体资料；词典事实不能被模型记忆替代 |
| `RWR-002` | 明确属性 | 品牌、通用名、剂型、包装数量/单位和人群等原始约束在候选中逐项保留；缺失、替换或扩大范围不得默认为通过 |
| `RWR-003` | 索引能力 | 候选 term 必须由索引目录返回、处于可用状态并带索引版本；未命中只记录为待处理候选，不能声称已具备召回能力 |
| `RWR-004` | 语义不确定 | 无法确认候选是否保持原意时返回 `unknown` 或 `no_rewrite`，说明缺口，不用相似字符串强行放行 |
| `RWR-005` | 明确冲突 | 跨品牌、跨剂型、丢失明确包装数量/单位或跨人群的候选拒绝；高出价、库存或商品标题不能覆盖冲突 |
| `RWR-006` | 词词结论 | 词词相关、索引命中和当前可投是三个字段；任何一个未确认都不能合并为“已通过” |

候选数量由任务和索引事实决定，不写死样本数量。候选生成只服务当前 Query，不扫描或发布全量词池。
