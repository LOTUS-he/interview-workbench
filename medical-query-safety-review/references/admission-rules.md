# Query 准入与风险规则

本文件定义 Query 语义审核的边界；当前供给、计划、预算和证据时效不在此文件定义。资格数值和资格字段条件只从 `eligibility-rules.yaml` 读取。

## 规则

| Rule ID | 适用对象 | 处理要求 |
| --- | --- | --- |
| `ADM-001` | 任务范围 | 仅审核已指定场域、城市、区域、时间窗口和目标；范围不完整先阻断，不默认扩展 |
| `ADM-002` | 高风险 Query | 命中问诊/诊断、剂量咨询、联合用药、副作用咨询、孕妇或婴幼儿敏感用药等排除场景时停止改写和商品扩展，保留拒绝理由 |
| `ADM-003` | Query 属性 | 原文明确表达的品牌、名称、剂型、包装数量、单位和人群必须保留；未表达属性不得补造 |
| `ADM-004` | 风险分层 | `L0` 表示停止，`L1` 表示可在证据满足时继续，`L2` 表示观察或人工确认；风险不因搜索量、出价或商业价值降低 |
| `ADM-005` | 不确定事实 | 属性、词典、风险或准入证据未知时标记 `unknown` 或阻断依赖判断，不把缺失当成安全通过 |

## 机器政策 ID 对照

以下稳定 ID 是 handoff 和确定性校验可引用的主 ID；上表 `ADM-*` 是本文件的解释性细则，二者不维护不同阈值。

| 机器政策 ID | 细则范围 | 权威细则 |
| --- | --- | --- |
| `ADMIT-001` | Query 准入、风险分层和高风险早停 | 本文件 `ADM-001`、`ADM-002`、`ADM-004` |
| `BRAND-001` | 明确品牌不得被候选或商品替换 | 本文件 `ADM-003`，并结合 `relevance-rules.md` |
| `FORM-001` | 明确剂型不得被候选或商品替换 | 本文件 `ADM-003`，并结合 `relevance-rules.md` |
| `PACK-001` | 明确包装数量/单位不得丢失、替换或被解释为含量 | 本文件 `ADM-003`，并结合 `rewrite-rules.md` |
| `AUDIENCE-001` | 明确人群必须保留，未知人群不能推断特殊适用 | 本文件 `ADM-003`，并结合 `relevance-rules.md` |
| `EVIDENCE-001` | 属性和风险判断必须引用可回溯的原文/资料证据 | 本文件 `ADM-005`，并结合 `output-contract.md` |

## 识别责任

agent 依据原始 Query、词典和已授权资料完成语义识别，并为已知属性提供 `raw_span` 与 `source_ref`。确定性脚本只检查类型、字段完整性、引用存在和已声明的硬冲突，不能以关键词相似替代医学语义判断。

“名称归一”只表示名称表达层面的标准化，不代表临床替代、疗效判断或用药推荐。缺少批准规则版本时，不继续依赖该规则作放行判断。
