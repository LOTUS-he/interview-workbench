# 术语表

| 术语 | 定义 | 容易混淆的边界 |
| --- | --- | --- |
| Query | 用户原始搜索表达，保存为 `raw_query` | 不是已经审核过的标准词，也不是商品标题 |
| query_id | 待审词条标识 | 不等于一次搜索的 `request_id` |
| request | 一次有效搜索请求 | 历史统计应在 request 粒度去重 |
| term | 关键词索引中的标准表达 | 索引命中不等于词词相关或商品合格 |
| candidate | 一个候选广告，本审核通常以 `ad_plan_id` 标识 | 同一商品的不同计划是不同候选 |
| SPU | 基础商品组 | 同 SPU 不代表 SKU 的剂型、包装或人群相同 |
| SKU | 具体商品规格记录 | 不能仅用 SPU 代替规格证据 |
| offer | 某门店对某 SKU 的供给记录 | 同一 SKU 在不同门店的库存和配送可能不同 |
| store | 门店及其配送区域 | 门店数不等于商家主体数 |
| current eligibility | 当前时点商品、门店、地域、库存和广告计划的资格事实 | 不是历史资格，也不是 Query 相关性 |
| historical replay | 与在线召回分开的历史标准词候选回放 | 只能证明潜在候选，不能证明线上展示或成交 |
| evidence | 本次运行保存的原始或标准化事实文件 | 路径存在不等于内容支持结论 |
| `source_ref` | 证据来源及可选 JSON Pointer | 必须能解析到本次 run 的 `evidence/` |
| `raw_span` | 原始 Query 中支持属性的连续文字片段 | 不能用只有置信度的描述替代 |
| `unknown` | 事实缺失、冲突、过期或无法确认 | 不能当作 `reject`，也不能当作 `pass` |
| 包装数量 | 例如 `pack_count` 与 `pack_unit` 的组合 | 不等于单片含量、有效成分含量或剂量 |
| 人群 | Query 或商品资料明确提供的适用人群标签 | `通用` 或缺失不代表儿童、孕妇等特殊人群适用 |
| 执行状态 | `success/partial/blocked/skipped` | 描述流程是否完成，不描述业务对象是否通过 |

术语仅用于统一字段和交接表达；缺失的医学、商业或政策事实必须列为待确认，不从名称或模型记忆推断。
